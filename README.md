### 🚀 Featured Projects

🔹 **Crop Calendar — Document-Grounded RAG System**
Building a document-grounded system that extracts, organizes and retrieves agricultural information from government documents using **document extraction, entity recognition, hierarchical chunking, embeddings and vector search**.

🔹 **CyberShield — AI-Powered SOC Dashboard**
An AI-assisted cybersecurity dashboard combining **RAG, threat intelligence, incident monitoring and security analysis**.

🔹 **Education Tutor for Remote India**
A PDF-based educational assistant designed to answer questions from provided learning materials using **semantic search, FAISS, embeddings and LLMs**.

🔹 **EZ-VIZ — Automated ML Platform**
A Streamlit-based platform for **data preprocessing, visualization and machine learning model training**, developed during a 36-hour hackathon.
